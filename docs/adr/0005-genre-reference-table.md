# 5. Собственный справочник жанров

Дата: 2026-08-18
Статус: принято

## Контекст

Источников данных два: TMDB (жанры с числовыми идентификаторами) и
неофициальный API Кинопоиска (жанры строками на русском). Если хранить жанр
так, как его прислал источник, коллекция быстро наберёт дубли: «фантастика»,
«научная фантастика» и Science Fiction станут тремя разными жанрами, а
группировка и фильтры по жанру потеряют смысл.

## Решение

Таблица `genres` — собственный справочник, заполняемый миграцией из списка
TMDB. Таблица `genre_external_map` связывает внешние названия с записями
справочника; для Кинопоиска в неё засеяны русские названия и известные
синонимы.

Кандидат с числовыми идентификаторами резолвится напрямую, кандидат со
строковыми названиями — через таблицу маппинга.

## Последствия

Положительные:

- Жанр в коллекции всегда один и тот же независимо от источника.
- Новый синоним добавляется строкой в таблицу маппинга, без изменения кода.
- Фильтр по жанру — обычный `JOIN`, а не сравнение строк.

Отрицательные:

- Незнакомое название жанра из Кинопоиска молча теряется. Фильм при этом
  сохраняется полностью, теряется только один ярлык; такие пропуски видны в
  данных и лечатся строкой в маппинге.
