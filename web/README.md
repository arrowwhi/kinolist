# Кинолист · Mini App

React + TypeScript, интерфейс по макетам Figma. Локальный Inter поставляется вместе
с приложением. Производственные запросы идут в `/api/v1` с Telegram initData;
тестовые данные не импортируются в приложение.

## Структура

- `src/app/` — запуск, маршрутизация, общая инвалидация данных, граница ошибок.
- `src/pages/` — композиция экранов: коллекция, жанры, фильтры, фильм, заметка,
  оценка и добавление. Страницы не импортируют друг друга.
- `src/widgets/app-shell/` — общий каркас экрана и нижняя навигация.
- `src/features/` — логика сценариев: коллекция и пагинация, поиск/подтверждение
  кандидата, форма оценки. Не зависит от страниц и маршрутизатора.
- `src/entities/movie/` — карточка, постер, рейтинг и представление данных фильма.
- `src/shared/ui/` — кнопки, поля, чипы, диалог, загрузка и ошибки.
- `src/shared/hooks/` — отменяемая загрузка, мутации и debounce.
- `src/shared/lib/` — форматирование, Telegram, общие типы навигации.
- `src/shared/styles/` — семантические токены, сброс и базовые стили.
- `src/api/` — типизированный HTTP-клиент и DTO. Данные не загружаются внутри
  кнопок, карточек и других UI-компонентов.
- `tests/` — проверки чистой логики и отдельный сервер тестовых данных.

CSS лежит рядом с соответствующими компонентами/сценариями, собирается в `main.tsx`.
Добавлять тяжёлый глобальный state manager для этого размера приложения не нужно:
URL хранит экран, `app` — настройки выборки, feature hooks — состояние запросов.

## Темы

Тёмная тема соответствует утверждённому макету. Цвета компонентов используют только
семантические CSS-переменные, а не значения палитры. В `tokens.css` подготовлена
палитра `[data-theme='light']`; переключатель и автоматический выбор темы пока не
добавлены. Цвета художественных заглушек постеров — контент, а не тема интерфейса.

## Поведение

- Поиск и фильтры сохраняются при переходе в фильм и назад.
- Статистика берётся из `summary`: поиск меняет результаты, но не количество
  по фильтрам и не среднюю оценку. Пагинация использует отдельный `total`.
- Даты группировки просмотренных — `watched_at`, отложенных — `added_at`.
- Устаревшие ответы при переключении фильтров игнорируются; начальные запросы
  отменяются через AbortController. Повторные отправки форм блокируются.
- При добавлении сначала выбирается кандидат и загружаются подробности, затем
  фильм подтверждается. «Уже смотрел» передаёт статус, оценку и отзыв одним запросом.
- Ручного выбора даты просмотра нет. Заметка и отзыв сохраняются независимо.
- Hash-маршрутизация поддерживает ссылки, browser back и кнопку Назад Telegram.

## Запуск и проверки

```sh
npm ci
npm run dev          # Go API на localhost:8080, нужна авторизация Telegram
npm run typecheck
npm test             # Node.js с поддержкой strip-types, рекомендуется Node 22.18+
npm run format:check
npm run build
```

Для изолированной проверки UI без доступа к рабочей БД:

```sh
npm run build
node tests/fixture-server.mjs
# http://127.0.0.1:4173 — только тестовые фильмы, все изменения в памяти процесса
```

Это отдельный инструмент разработки: он не ослабляет авторизацию Go API и не
включается в сборку. Параметр `?theme=light` на тестовом сервере показывает подготовленную
светлую палитру. Полный Telegram-сеанс дополнительно проверяется внутри клиента Telegram.
